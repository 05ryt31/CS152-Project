# Migration matrix (Issue #15)

`matrix.json` is generated by `python pipeline/matrix.py`; edit the script, not the JSON.

## Paradigm mapping

| Language | Paradigm (analysis) | Family (intra/inter grouping) | Runtime (harness) |
|---|---|---|---|
| Python | imperative | imperative-oo | Python 3.14 |
| JavaScript | imperative | imperative-oo | Node 26 |
| Java | oo | imperative-oo | JDK 25 |
| Scheme | functional | functional | CHICKEN 5.3 |
| Haskell | functional | functional | GHC 9.14 |
| Prolog | logic | logic | SWI-Prolog 10 |

Two fields on purpose. `paradigm` is what the analysis reports (RQ3 asks about imperative vs OO as well).
`family` decides intra vs inter: the proposal counts Python → Java as intra-paradigm, so imperative and OO form
one family. Prolog has no intra pair; every Prolog pair is inter.

## Pairs

All 30 ordered pairs of the six languages are in the matrix, each tagged `intra` or `inter` and given a priority.

| Group | Pairs | Count |
|---|---|---|
| intra | Python ↔ JavaScript, Python ↔ Java, JavaScript ↔ Java, Scheme ↔ Haskell | 8 |
| inter, priority 1 | every pair touching Prolog (10), Python ↔ Haskell, Java ↔ Haskell | 14 |
| inter, priority 2 | Python ↔ Scheme, Java ↔ Scheme, JavaScript ↔ Scheme, JavaScript ↔ Haskell | 8 |

Priority 1 (22 pairs) is the minimum for RQ1-RQ3: all intra pairs as the baseline, the logic paradigm in both
directions, and the imperative-oo → functional contrast via Haskell. Priority 2 completes the matrix and runs
only if the budget allows after priority 1 is done.

## Run count

| Problems | Priority 1 only | Full matrix |
|---|---|---|
| 15 | 330 translations | 450 |
| 20 | 440 translations | 600 |

At roughly 30-60 s per translation on a Colab T4 with the 7B model, the full matrix for 20 problems is
5-10 GPU-hours, inside the 8 GPU-hour go/no-go bound in `MODEL.md` only if we stay near the lower end; priority 1
alone is 4-7 hours. Decide after the first timed run on `smoke_io`.

## Sources

A pair runs only when a source program in `src` exists for the problem. Which non-Python sources exist is
decided in #7 (hand-written subset plus verified LLM translations); the pipeline skips missing sources and
records them as `skipped: no_source` so the matrix shows gaps instead of silently shrinking.

## JSON shape

```json
{
  "version": 1,
  "languages": {"python": {"name": "Python", "paradigm": "imperative", "family": "imperative-oo", "ext": "py", "fence": "python"}, "...": {}},
  "pairs": [{"src": "python", "tgt": "haskell", "group": "inter", "priority": 1}, "..."]
}
```

`ext` is the target file extension the pipeline writes; `fence` is the code-block tag the prompt asks for and the
extraction rule matches (see `prompts/v1.md`).
